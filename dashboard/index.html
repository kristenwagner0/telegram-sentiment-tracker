Setup steps:
  1. Run telegram_sentiment.py on your Telegram export
  2. Optional: refresh_keywords.py and translate_output.py for better complaints + English
  3. Import the CSV into Google Sheets · Share as "Anyone with the link"
  4. Paste the sheet URL above and click Connect
Use SentimentTrack on your own data
Sentiment analysis runs on your computer (free). This hosted site is the interactive viewer.
Run locally:
  1. Export your Telegram chat as JSON from Telegram Desktop
  2. Clone the repo: GitHub
  3. Run python telegram_sentiment.py -i exports/your_chat/result.json --lang ko
  4. Open the dashboard locally, or drop your output CSV below
